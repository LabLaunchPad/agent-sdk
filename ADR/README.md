# ADR/

Architecture Decision Records.

**Source-of-truth status: CANONICAL** (decisions).

One file per decision, numbered sequentially, never rewritten in place once
`status: stable` — supersede with a new ADR instead (`status: deprecated`).
Before modifying any existing architectural decision, read its ADR first.

Each ADR is an [OKF v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
concept (`type: Architecture Decision`) — see [ADR-0007](0007-adopt-okf-v0-2.md).

Use [`TEMPLATE.md`](TEMPLATE.md).
