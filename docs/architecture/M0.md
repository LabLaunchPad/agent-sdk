# M0 — scope, gate, and what it is allowed to claim

**Status: `BLOCKED_PENDING_ARCHITECTURE_SIGNOFF`.**

M0 is a **control experiment**, not a product milestone and not a production runtime. Its purpose
is to convert an architecture argument into a falsifiable result. No runtime code may be written
until the amendments in [`../adr/amendments/`](../adr/amendments/README.md) are signed off — the
rule the [conflict register](conflicts/README.md) sets and this document does not relax.

## What M0 is

Two implementations of the same control plane — `m0-rust` and `m0-ts` — consuming **identical**
canonical schemas, fixtures, scripted model transcript, capability fixtures, policy rules,
checkpoint fixtures and replay fixtures. Same workload, same proofs, same event output.

`m0-ts` is a **reference implementation and control**. It is not a candidate production runtime
and must not be described as one.

The question M0 answers is narrow and should stay narrow:

> Can a minimal Rust control plane demonstrably provide the required correctness, replay, security
> and resource behaviour while preserving a clean TypeScript ecosystem boundary?

The question it does **not** answer is "which language is better". That framing is not falsifiable
and no result here should be reported as settling it.

## Relationship to ADR-0001

[ADR-0001](../../ADR/0001-typescript-canonical-language.md) makes TypeScript the canonical
implementation and states that Go or Rust components are considered *"only after profiling
identifies a hot path, never for anticipated scalability."*

M0 **is** that profiling. ADR-0001 remains `status: stable` and unamended. If the measured result
favours Rust, a superseding ADR cites M0's evidence; if it favours TypeScript, ADR-0001 stands and
the Rust tree is deleted. Nothing here overrides ADR-0001 — it tests it, which is what the ADR's
own revisit trigger asks for.

ADR-0001 also already makes **JSON Schema the canonical contract**, with TypeScript/Zod as one
runtime representation. That is what makes a two-language experiment possible without a second
architecture: both implementations consume the same schemas, and neither owns them.

## The proof matrix

Both implementations, all twelve:

| # | Proof |
|---|---|
| 1 | Provider substitution |
| 2 | Policy `ALLOW` |
| 3 | Policy `DENY` |
| 4 | Approval |
| 5 | Capability failure |
| 6 | Verification failure |
| 7 | Crash / resume |
| 8 | **Strict-fold replay** — the only replay mode gated ([AMD-004](../adr/amendments/AMD-004-replay-modes.md)) |
| 9 | **Content-derived idempotency** ([AMD-006](../adr/amendments/AMD-006-content-derived-idempotency.md)) |
| 10 | Zero-network |
| 11 | No hidden state — *as fold equivalence* ([CONFLICT-014](conflicts/CONFLICT-014-no-global-state-vs-ecosystem.md)) |
| 12 | Identical logical replay from shared fixtures |

Proof 12 is the actual experiment: the two event streams must be **logically equivalent**, compared
by a cross-implementation differ, not by inspection.

Proofs 8 and 11 were both **unfalsifiable as originally written** — "replay" named two operations,
and "no hidden state" was a source-code property rather than a behavioural one. Their current
wording is a direct result of the register.

### Negative suite

Positive proofs alone would have passed while permitting privilege escalation. Required:

- every widening pair in the lattice is rejected
- `network_to_execute_is_rejected_as_widening`
- `incomparable_classes_are_rejected_rather_than_ordered`
- transform terminates rather than looping
- transform cannot leave its capability namespace
- `duplicate_tool_call_id_across_runs_does_not_collide`
- `crash_resume_rederives_identical_key`
- terminal write by a non-owner is rejected

## Honesty note — what counts as evidence

This register and this document are the product of comparing several agent runtimes. Some of that
comparison is worth less than it appears, and saying so is cheaper than being caught by it later.

1. **Vendor marketing is not evidence.** Where a cited product's architecture is not publicly
   documented, that is recorded as `UNKNOWN` rather than treated as precedent. A system doing
   something is not proof it works; it is proof someone shipped it.
2. **A benchmark from another project is not our benchmark.** No number enters an ADR without
   reproducible raw data collected on a stated machine with a stated toolchain.
3. **A weighted decision score is not a measurement.** Where scoring is used, the score, its
   confidence, and its evidence basis are recorded separately, and sensitivity is checked: if the
   winner changes under reasonable assumptions, the decision is `UNSTABLE` and is not locked.
4. **Cross-compilation is not platform support.** Portability claims use `DESIGNED` /
   `COMPILE-CHECKED` / `RUNTIME-VERIFIED` / `PLATFORM-SUPPORTED`, and `PLATFORM-SUPPORTED` requires
   a real runner. There is currently no Windows, Android, iOS or browser runner, so those stay
   `UNVERIFIED`.
5. **Popularity is not architecture.** Convergence between OpenAI's Agents SDK, DeerFlow and
   AgentScope on a harness model is genuinely informative about *what problem exists*. It is not
   evidence about *which solution is correct*, and it is cited here only in the first sense.
6. **The sixteen unverifiable ADR citations stay marked.** Sixteen of the twenty-six ADRs this
   register originally cited cannot be produced. Those conflicts stand on their restated premises,
   and the [provenance note](conflicts/README.md#citation-provenance) records which.

## Gate

`ARCHITECTURE_GO` requires **all** of:

- [ ] Every `BLOCKING` conflict has a signed-off amendment
- [ ] Twelve proofs pass in `m0-rust`
- [ ] Twelve proofs pass in `m0-ts`
- [ ] Negative suite passes in both
- [ ] Shared fixtures produce logically equivalent event streams
- [ ] Benchmark register exists with reproducible raw data
- [ ] Portability claims scoped honestly per rule 4
- [ ] Deferred decisions recorded with their revisit triggers

Anything else is `ARCHITECTURE_BLOCKED`, reported with the **smallest remaining blocker list** —
not a status page.

## Deferred, with triggers

Serialization is **not** deferred — [AMD-005](../adr/amendments/AMD-005-canonical-encoding.md)
settles the canonical encoding, because it is schema- and ABI-affecting. The internal snapshot
format may legitimately differ from the interchange encoding and *is* open.

Still deferred: IPC mechanism, async runtime, storage engine, WASM host configuration, and the
WASM plugin boundary measurement — the last because
[AMD-007](../adr/amendments/AMD-007-plugin-abi-scope.md) leaves per-class transport bindings
unwritten, and measuring a transport before its binding exists benchmarks a placeholder.
