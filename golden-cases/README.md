# golden-cases/

Frozen input/output cases that must keep behaving identically across
refactors, model substitutions and runtime changes.

**Source-of-truth status: CANONICAL** (regression evidence).

A golden case changes only through an explicit, reviewed decision — an
unexplained golden-case update is a regression, not a fix.

## Phase 0 contents

Empty. Golden cases arrive with the first real behaviour in Phase 3.
